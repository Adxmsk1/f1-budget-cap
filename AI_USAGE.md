# How I used AI

I used AI as a coding assistant on this project. The main places it helped:

- **The visual side** - the Power BI cover and background images, and the scripts that write the report pages.
- **Testing** - drafting the pytest tests in `tests/` and the SQL data checks in `sql/03_checks.sql`.
- **Writing** - drafting the README and data dictionary.

When the new checks first ran, they showed nine pit stops with no time rather than the two I'd documented, so I
corrected the data dictionary.
